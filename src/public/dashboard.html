Gerenciar lojas

As lojas deste servidor são definidas pela variável de ambiente STORES_CONFIG. Para alterar, atualize essa variável na hospedagem e reinicie a aplicação — não é possível editar por aqui.
Como preencher
  • Chave (key) — identificador único da loja: só letras minúsculas, números e hífen (ex: madesa-mx). Não pode ser alterada depois de criada; para renomear, exclua e crie de novo.
  • Nome — como a loja aparece no painel (ex: "Madesa México").
  • Domínio myshopify — termina em .myshopify.com. Fica em Shopify Admin → Configurações → Domínios.
  • Autenticação — escolha uma:
    • Token fixo (shpat_): gerado em Shopify Admin → Configurações → Apps e canais de vendas → Desenvolver apps → (seu app) → API credentials. Nunca expira sozinho.
    • OAuth (client_id/secret): use as credenciais do app criado no Partner Dashboard. Depois de salvar, abra /oauth/{chave}/install (logado no painel) para autorizar — o token passa a se renovar sozinho.
  • Origens permitidas — uma URL por linha (ex: https://madesa.mx): o site que pode enviar leads para essa loja.
  • Tags padrão — opcional, aplicadas a todo contato criado por essa loja (uma por linha).
  • Código do país — DDI para completar telefones sem prefixo (ex: 52 México, 55 Brasil).
  • Aceite de marketing — se marcado, contatos criados por essa loja entram com opt-in de e-mail marketing na Shopify.
